# Verify before done

Use this before you tell the human a task is finished.

1. Restate the path they asked for, in one sentence.
2. Run that path. A test count, a lint result, or a file that exists is not the path unless they asked for that.
3. If the check fails, say the failure and the next cause. Do not call a workaround the finish.
4. If you cannot run the check, say what is missing. Do not say done.

Done when the named path returned the result they asked for, and you can point at that result.
